# Calcit 0.13.77 compatibility / Calcit 0.13.77 兼容

## 中文

- 将 Calcit 与 `@calcit/procs` 对齐到正式发布的 0.13.77，并准备 pointed-prompt 0.0.10。
- 显式收窄坐标与键盘事件的 JS 边界类型，补充可复用空样式，并统一 CSS 值，清除 0.13.77 下 9 个预处理类型错误。
- 为共享样式 map 声明 `Map<Tag, Dynamic>` 边界，保留原有自定义样式值类型与渲染行为。
- CI 使用可读的 `setup-calcit@v1.4.0` release tag，不再以 commit hash 代理版本号；同时启用严格 Caps 与 `--check-only`。

## English

- Align Calcit and `@calcit/procs` with the released 0.13.77 toolchain and prepare pointed-prompt 0.0.10.
- Narrow coordinate and keyboard-event JS boundaries, introduce a reusable empty style, and normalize CSS values to eliminate all nine 0.13.77 preprocessing type errors.
- Declare `Map<Tag, Dynamic>` boundaries for shared style maps while preserving custom style value types and rendering behavior.
- Use the readable `setup-calcit@v1.4.0` release tag instead of a commit hash proxy, and add strict Caps plus `--check-only` CI gates.
